# 分诊标签

技能使用五个标准分诊角色。本文件把这些角色映射到本仓库工单跟踪器实际使用的标签字符串。

| mattpocock/skills 中的角色 | 本仓库标签 | 含义 |
| -------------------------- | ---------- | ---- |
| `needs-triage`             | `needs-triage`       | 维护者需要评估这条工单 |
| `needs-info`               | `needs-info`         | 等待报告者补充信息 |
| `ready-for-agent`          | `ready-for-agent`    | 规格完整，可交给无人值守 agent |
| `ready-for-human`          | `ready-for-human`    | 需要人来实现 |
| `wontfix`                  | `wontfix`            | 不做 |

技能提到某个角色时（例如「打上 AFK-ready 分诊标签」），使用本表右侧对应的标签字符串。

若跟踪器里已经用了别的名字，只改右列即可。
