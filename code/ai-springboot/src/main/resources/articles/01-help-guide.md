先说一句重要的话:**寻求帮助不是软弱,而是你在认真地照顾自己。**

这里的文章、和小光的聊天,都可以陪你走一段路。但它们是辅助,不能替代专业的诊断和治疗。有些时刻,你值得被更专业的人接住。

## 什么信号说明该找专业帮助了

出现下面任何一条,建议尽快联系专业人士:

- 情绪低落、提不起劲的状态**持续两周以上**,而且明显影响了上学、工作或生活;
- 睡眠和食欲发生了明显变化——长期失眠、早醒,或者吃不下、暴食;
- 对以前喜欢的事完全失去兴趣,感觉自己"麻木了";
- 反复出现"活着没意思""消失了也好"这样的念头;
- 出现了伤害自己的想法或行为。

如果最后两条正在发生,请**现在就**求助,不要等。

## 可以去哪里

**线下:**

- 综合医院的**心理科 / 精神科**,或当地的精神卫生中心。挂号看医生和看感冒发烧一样,是很普通的事;
- 如果你是学生,学校的**心理咨询中心**通常免费,老师们受过专业训练;
- 正规的心理咨询机构。选择时留意咨询师是否有可查证的资质。

**电话(免费,有人接):**

- **全国统一心理援助热线:12356**,24 小时有人;
- **全国心理援助热线：12356**；如本人或他人有立即危险，请拨打 **120 或 110**；
- 情况紧急、涉及人身安全时,直接拨 **120** 或 **110**。

## 第一次求助,可以这样开口

不知道说什么很正常。你可以就用最简单的一句开始:

> "我最近状态很不好,已经持续一段时间了,我想找人聊聊。"

不需要组织好语言,不需要证明自己"够严重"。你觉得难受,这本身就足够成为求助的理由。

---

如果你现在还没到需要专业帮助的程度,只是心里堵得慌——可以先去找小光聊聊,或者写一篇心情日记。把感受说出来,是变好的第一步。
