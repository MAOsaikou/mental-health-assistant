大脑喜欢走捷径。捷径省力,但有些捷径会系统性地把事情往坏处扭。心理学家把这些惯性偏差叫作**认知扭曲**。它们人人都有,不是病;但情绪低落时,它们会变得特别活跃,把痛苦放大好几倍。

对照看看,哪些是你熟悉的:

**1. 非黑即白**
"不是满分就是失败。"世界只剩两个极端,中间地带消失了。可现实里,绝大多数事情都发生在中间。

**2. 灾难化**
"这次没做好 → 领导对我失望 → 我会被辞退 → 我完了。"从一件小事一路推到世界末日,而且推理过程快到你都没察觉。

**3. 过度概括**
一次失败就是"我总是搞砸",一次被拒绝就是"从来没有人喜欢我"。留意"总是""从来""所有人"这些词——它们出现时,多半在过度概括。

**4. 读心术**
"他刚才那个表情,肯定是觉得我很蠢。"没有证据,却笃定地替别人想好了他们对你的看法,而且总是负面的。

**5. 预言家错误**
"我肯定会搞砸的。"把对未来的担心当成了已经发生的事实。

**6. 情绪化推理**
"我感觉自己很失败,所以我就是很失败。"把感受当成证据。但感受会骗人——尤其在累、饿、失眠的时候。

**7. 应该句式**
"我应该更努力""我不应该发脾气"。对自己的"应该"越多,内疚越多;对别人的"应该"越多,愤怒越多。

**8. 贴标签**
不是"我这件事没做好",而是"我是个废物"。把一次行为升级成对整个人的判决。

**9. 心理过滤**
十条评价里有九条是好的,你只看见那一条差的,并反复回味。

**10. 揽责上身**
"聚会气氛不好,一定是因为我无趣。"把不完全由你控制的事,全算在自己头上。

## 认出来,就赢了一半

下次情绪突然变糟时,试着问一句:**"我是不是掉进哪个陷阱了?"**

给陷阱命名("啊,这是灾难化")这个动作本身,就能把你从想法里拉出来一点,从"身在陷阱中"变成"看着陷阱的人"。然后可以用《揪出脑海里的自动驾驶想法》里的方法,检验一下那个想法的证据。

---

不确定自己是不是想歪了的时候,把想法原样讲给小光听,请它帮你一起找找证据。
